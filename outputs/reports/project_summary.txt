Project Type: Academic Major Project

PROJECT OVERVIEW
----------------
An interactive Streamlit-based retail intelligence system combining
data analytics, forecasting, store segmentation and business insights.

DATASET
-------
Records analyzed: 73,000
Original columns: 19
Analysis period: January 2023 to December 2024
Engineered dataset: 26 columns

DATA QUALITY
------------
Missing values: 0
Duplicate rows: 0
Invalid dates: 0
Negative sales/units: 0

WORKFLOW
--------
1. Data cleaning and validation
2. Feature engineering
3. Exploratory data analysis
4. Sales forecasting
5. K-Means store segmentation
6. Anomaly detection
7. AI-powered business recommendations
8. Interactive Streamlit dashboard

FEATURE ENGINEERING
-------------------
Year, Month, Month Name, Quarter, Day, Day of Week and Week of Year.

The dashboard analyzes sales by:
- Month and year
- Product category
- Region
- Store
- Customer type
- Payment mode
- Brand
- Promotion
- Holiday
- Discount
- Stock
- Store rating
